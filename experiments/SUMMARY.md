# Итог исследования (bottom line)

> Короткая выжимка. Полный лог траектории — `RESULTS.md`, все замеры — `eval_full_ledger.jsonl`.
> Обновлено: 2026-06-14.

## Задача
Мультимодальный визуальный поиск по одежде Avito (~1M товаров). Три режима: **image** (фото→похожие),
**txt** (русский текст→фото), **multimodal** (фото + текст-модификатор). Цель — поднять mm/all, не уронив txt.

## Как меряем (eval) — БЕЗ ручной разметки
- Протокол продакшен-образный: запрос → ранжированная выдача (FAISS) → MRR / Recall@K.
- Метки релевантности **автоматические**: «релевантно = тот же `item_id`» (txt: текст→картинки товара;
  image: картинка→другие фото того же товара). Человеческих суждений нет.
- Каталог = **52 243 картинки** (val-таргеты + 50k дистракторов), `scripts/eval_full.py`. Старый eval на
  477 картинок завышал метрики ~×3 — пользоваться только eval_full.
- ⚠️ Настоящей продовой оценки (живые запросы + человеческая релевантность) НЕТ — это отдельная работа.

## Лучшая модель
**SigLIP 2 ViT-L-16 (256px) + дообучение на синтетических запросах** (lr 1e-6, 2 эпохи).
Чекпойнт: `experiments/l16_synth_lr1e-6/best_ep2_model_only.pt`.

| метрика | значение |
|---|---|
| all-MRR | **0.327** |
| txt | 0.388 |
| image | 0.370 |
| multimodal | 0.223 |

## Прогресс all-MRR (каталог 52k)
| этап | all |
|---|---|
| zero-shot xlm-CLIP (старая база) | 0.151 |
| дообученная xlm-CLIP (наш свип) | 0.188 |
| SigLIP 2 L-16 zero-shot (смена базы) | 0.290 |
| SigLIP 2 gopt-1B zero-shot | 0.304 |
| **L-16 + синтетика (ИТОГ)** | **0.327** (+117% к baseline) |

## Ключевые решения и почему
1. **Сменили базовую модель** на SigLIP 2 (мультиязычная, знает русский) — дало больше, чем весь тюнинг старой
   модели. Marqo-FashionSigLIP (доменная, но английская) проиграла из-за перевода.
2. **Дообучаем — ДА, но только на синтетике.** Шаблонные запросы из метаданных при дообучении ВРЕДЯТ
   (ломают txt: 0.370→0.297). Синтетические запросы Qwen2-VL **по фото** (видят принт/фасон/длину/фактуру —
   сигнал, которого нет в метаданных) — дообучение ПОМОГАЕТ (txt 0.370→0.388, mm +54%).
3. **1 RPS не ограничивает** выбор модели (латентность на запрос мизерная; дорого только офлайн-индексирование).

## Что НЕ сработало (проверено, отклонено)
- Реранкер (Qwen2-VL pointwise поверх top-K) — вредит (bi-encoder уже силён, 0-10 слишком грубо).
- Разрешение 384px — помогает zero-shot, но после синтетики ничья при 2.3× стоимости.
- Hard-negative батчинг (категорийные батчи) — нейтрально.
- Мульти-фото (несколько ракурсов) — не помогает retrieval.
- Заморозка башен, высокий lr — вредят (хрупкий txt).
